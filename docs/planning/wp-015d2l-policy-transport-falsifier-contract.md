### Gameplay-world question

> Does the D2K local policy wake transport as a role-neutral response-policy
> improvement across F4, or does selecting the obvious lethal response merely
> transfer initiative to whichever actor reaches the preparation-response
> carrier first?

The directional wager is deliberately relational. D2K exposed a legitimate
first-cycle Cocoon branch and a later carrier with three immediately lethal
Threadball responses. D2L does not assume that either observation supplies a
general policy. It compares three fixed shadow transforms so terminal choice,
residue-only tie handling, response-carrier timing, and global opportunism make
different predictions over the same source carriers.

### Fixed analytical variants

All variants delegate to the unchanged public `choose_action` result unless
their exact condition applies. An immediate win means that applying one legal
action through unchanged F4 produces a finished carrier won by the active
actor. Candidate enumeration is pure and must not mutate its source carrier.

1. `baseline_v0`
   - exact existing policy selection;
   - no shadow substitution.
2. `terminal_tie_residue_v0`
   - only when the existing selected action is already an immediate win;
   - choose among all immediate wins by least Escape-Slack expenditure, then
     least absolute displacement, then ordinal action key;
   - changes terminal path residue only and is a destructive control against
     treating symmetry cleanup as gameplay repair.
3. `preparation_response_lethal_guard_v0`
   - only when the active actor has no live Spoolburst preparation, the
     opponent has live preparation, and counter-preparation remains legal;
   - if an immediate win exists, choose it by the same residue-stable order;
   - otherwise delegate unchanged selection.
4. `global_lethal_guard_v0`
   - at every carrier, choose an immediate win when one exists using the same
     residue-stable order;
   - this is the deliberately broad destructive control.

The actor-relative property is mirror equivariance, not a preferred absolute
left/right direction. `stay` is selected when it uniquely minimizes both
Escape-Slack expenditure and displacement; toward/away direction remains
visible if a later carrier requires a final ordinal tie-break.
