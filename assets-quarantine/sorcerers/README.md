# Sorcerers Quarantine

This tree is for local review scaffolding only.

`lorgan3/sorcerers` is GPL-3.0 and mixes many third-party asset sources. Nothing
in this quarantine is automatically approved for product use.

Rules:

- Do not copy Sorcerers code into this repository.
- Do not commit raw Sorcerers assets.
- Do not move a file into `assets/` without a complete approved manifest entry.
- Treat Sorcerers credits as pointers to original sources, not as final license
  evidence.
